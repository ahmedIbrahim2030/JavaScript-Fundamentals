# JavaScript Fundamentals – Part 1

A beginner-friendly JavaScript practice project focused on core programming concepts and essentials of the language.

This project is built as a simple front-end exercise using HTML and JavaScript, and it demonstrates the foundation of JavaScript programming through small code examples and hands-on learning.

## Overview

JavaScript Fundamentals – Part 1 introduces learners to the basics of JavaScript, including:

- Variables and constants
- Data types
- Operators and expressions
- Strings and template literals
- Conditional statements
- Type conversion and coercion
- Boolean logic and comparison
- Basic JavaScript syntax and best practices

The project is intentionally lightweight and easy to run, making it suitable for learning and experimentation.

## Project Structure

```text
fundamentals_01/
├── index.html
├── script.js
└── README.MD
```

- `index.html` – Contains the basic page structure and loads the JavaScript file.
- `script.js` – Contains the JavaScript examples and practice code.
- `README.MD` – Project documentation.

## Technologies Used

- HTML5
- CSS3 (embedded in the page for simple styling)
- JavaScript (ES6+ syntax examples)

## Getting Started

### 1. Open the project folder

Navigate to the project directory in your file explorer.

### 2. Launch the app

Open `index.html` in a browser.

You can either:

- double-click the file, or
- serve it locally with a simple development server if preferred.

### 3. Explore the JavaScript code

Open `script.js` to review the examples and experiment with the code.

## Learning Topics Covered

This repository focuses on the foundational concepts that every JavaScript developer should understand:

- Declaring variables with `let` and `const`
- Understanding primitive data types
- Performing arithmetic and assignment operations
- Concatenating strings and using template literals
- Writing `if / else` logic
- Understanding truthy and falsy values
- Converting values with `Number()`, `String()`, and related methods
- Learning how JavaScript coerces values during operations
